# Blank templates

Put only sanitized, reusable Excel templates here.

Before publishing a template:
- Remove project IDs, customer names, employee identities, working-hour records and production outputs.
- Confirm it is genuinely blank (including hidden cells, defined names, comments and metadata).
- Run the workbook audit and open a copy in desktop Excel 2010.
- Keep template changes versioned and document changed formulas.

Do not upload the populated AL Decision Maths workbook to this public repository.
